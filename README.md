# 🎹 Шпаргалка пианиста

Интерактивный веб-справочник для визуализации аккордов при обучении игре на пианино.

## Возможности
- **Справочник:** 12 нот × 12 аккордов (6 трезвучий и 6 септаккордов, включая доминантсептаккорд, большой мажорный и малый минорный), обращения с русскими названиями
- **Нотный стан:** аккорд показывается нотами в скрипичном ключе
- **Клавиатура на 3 октавы** с анимацией нажатия клавиш и правой педалью
- **Тренажёр:** «найди аккорд на клавишах» и «прочитай ноты» (4 варианта ответа), счёт и серия
- **Играет сам:** гармонические последовательности (поп, баллада, джаз ii–V–I, блюз), аккордами или арпеджио, регулировка темпа и тональности
- **Живой звук пианино:** свои записи из `sounds/` либо сэмплы рояля Salamander (Alexander Holm, CC BY 3.0)
- Названия нот C D E ↔ до ре ми, адаптивная вёрстка

## Технологии
HTML5, CSS3, JavaScript, Web Audio API, SVG. Один файл `index.html`, без сборки.

## Запуск
Откройте `index.html` в браузере. Для публикации включите GitHub Pages: Settings → Pages → Deploy from a branch → main / root.
Свои записи из `sounds/` работают только на GitHub Pages или локальном сервере (`python -m http.server`).
